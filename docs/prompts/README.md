# AI にデータを作らせるプロンプト

手で工程表を入力する代わりに、ChatGPT / Claude などに JSON を作らせて読み込む手順です。

1. アプリの「▸ AI にデータを作らせる」を開く
2. 対象の業務を一言で書き、「プロンプトをコピー」する
3. AI に貼り付けて送る。AI が質問してきたら答える
4. AI の回答 (JSON) をそのままアプリの「AI の回答を貼り付け」欄に貼って「読み込む」。
   ```json フェンスや前後の説明文が付いていても自動で取り除きます

アプリ外で使いたい場合は [vsm-data-prompt.md](vsm-data-prompt.md) をコピーしてください。
プロンプトの本体は `src/domain/promptTemplate.ts` にあり、単位やタイトルはアプリ側で自動で埋まります。

## うまく作らせるコツ

- 「誰が」「何をしたら」「次に誰に渡るか」を箇条書きで渡すと工程の切り方が安定します
- 数値は AI が仮の値を入れて `note` に「要確認」と書くので、読み込んだ後に工程表で直してください
- 「待ち」は "着手までに放置されている時間"、"LT" は "着手してから完了まで" と伝えると混同が減ります
